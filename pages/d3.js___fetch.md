- ## Summary
	- 이 자체로 모듈이다. 자바스크립트에 있는 내장 fetch() API를 내부에서 호출해 데이터를 불러오는 기능을 구현한 일종의 wrapper다.
- ## Steps
	- *d3.dsv(delimiter, input, init, row)*
		- `delimiter` (문자열): 데이터를 나누는 구분자 `, (쉼표), \t (탭), | (파이프)`등 딱 한 글자의 문자열이어야 한다.
		- `input` (문자열): 가져올 파일의 경로(URL).
		- `init` (객체, 선택 사항)
			- 브라우저 내장 fetch() API에 전달할 설정 옵션이다. 인증 헤더(Headers), 요청 메서드(Method) 등을 지정할 수 있다.
			- 인증 정보를 동시에 전송. 원시데이터 접근에 인증을 요구하면 필요하다.
				- ```js
				  d3.csv("/api/private-data", {
				    headers: {
				      "Authorization": "Bearer YOUR_TOKEN_HERE" // 서버에 신분증 제시
				    }
				  })
				  ```
			- 데이터 요청. 원시 데이터 호출이 API 기반일 때 필요하다.
				- ```js
				  d3.json("/api/search", {
				    method: "POST", // 가져오는 게 아니라 데이터를 보내며 요청함
				    headers: { "Content-Type": "application/json" },
				    body: JSON.stringify({ category: "electronics", minPrice: 1000 })
				  })
				  ```
			- 캐시 제어. 브라우저에 저장된 데이터보다 데이터 갱신이 더 중요한 경우.
				- ```js
				  d3.tsv("/api/stock-prices", {
				    cache: "no-cache" // 브라우저 저장소 쓰지 말고 무조건 서버에서 새로 받아와!
				  })
				  ```
		- `row` (함수, 선택 사항)
			- 불러온 데이터의 **각 행**을 어떻게 변환할지 결정하는 함수이다. 
			  D3는 기본적으로 데이터를 문자열로 읽어오는데, 이 함수를 이용해 숫자나 날짜 데이터로 미리 변환할 수 있다.
			- ```javascript
			  const data = await d3.dsv(",", "example.csv", (d) => {
			    return {
			      year: new Date(+d.Year, 0, 1), // convert "Year" column to Date
			      make: d.Make,
			      model: d.Model,
			      length: +d.Length // convert "Length" column to number
			    };
			  });
			  ```
			- 아래처럼 그냥 함수 객체를 불러와도 된다.
			- ```js
			  d3.csv("data/weekly_temperature.csv", d3.autoType)
			    .then(data => {
			      console.log("변환된 데이터:", data); // 숫자와 날짜가 자동으로 변환됨 [5]
			    });
			  ```
	- *d3.csv(input, init, row)*
		- 구분자가 `,`(쉼표)인 점을 빼면 위의 `d3.dsv()`와 동일하다.
		- ```js
		  const data = await d3.csv("example.csv");
		  ```
