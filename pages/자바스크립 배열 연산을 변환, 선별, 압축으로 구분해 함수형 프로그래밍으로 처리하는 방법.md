- ## Steps
	- d3.js에서 함수형 프로그래밍을 구현하고자 할 경우 배열값의 불변성(immutability)을 유지하기 위해 다음 메서드를 활용한다.[^1]
		- 즉 아래에서 언급하는 메서드는 원본 배열을 수정하지 않은 채 결괏값으로 새로운 배열을 반환한다. 따라서 원본 배열의 불변성을 유지할 수 있다.
		- d3.js에서 주로 행하는 배열 연산은 변환(transformation), 선별(filtration), 축소(reduction/summarizing)이다.
			- 변환은 기존 배열과 1:1 대응하는 원소를 갖는 새로운 배열을 반환한다.
			- 선별은 기존 배열에서 조건에 부합하는 원소만을 갖는 부분 집합을 새로운 배열을 반환한다.
			- 축소는 기본 배열을 하나의 값을 압축해 반환한다.
			- ```js
			  const transformedArray = sourceArray.map(x => x * 2);
			  const filteredArray = sourceArray.filter(x => x > 0);
			  const reducedValue = sourceArray.reduce((accumulated, currentValue) => accumulated + currentValue, 0);
			  ```
		- 함수형 프로그래밍에서는 위 연산을 명령형(imperative)이 아닌 선언적(declarative) 구문으로 처리한다.
		- 자바스크립트의 배열 메서드는 배열 원소가 객체인 경우 얕은 복사본(shallow copy)을 만든다. 즉 복사한 배열 내부의 원소는 원본 배열의 원소를 참조한다. 따라서 사본에서 객체를 수정하면 원본 배열의 값도 따라서 바뀐다.
		- #### 변환
			- 1. `for` 대신 `map`을 사용한다. 구문은 아래와 같다.
			- ```js
			  // 기존 for 방식
			  const result = [];
			  for (let item of array) {
			      result.push(item * 2);
			  }
			  // 다른 코드 100줄...
			  for (let item of array) {
			      result.push(item * 3);  // 어? 같은 변수 재사용
			  }
			  // result 망가짐
			  ```
			- 코드의 흐름에 집중한다면 가독성이 떨어질 수도 있다. 적어도 나는 그렇다. 하지만 변수명을 일일이 기억할 필요없이 바로 원하는 결과를 참조하는 변수를 확보할 수 있다. 실제로 쓰면 아래와 같다.
			- ```js
			  // map 방식
			  const result1 = array.map(x => x * 2);
			  const result2 = array.map(x => x * 3);
			  // 각각 독립적, 충돌 없음
			  ```
		- #### 선별
			- `if...then push()`대신 `filter()`를 사용하는 이유를 설명한다.
			- ```js
			  const result = [];  // 이거 선언해야 함
			  for (let item of array) {
			      if (item > 10) result.push(item);
			  }
			  ```
			- 이는 아래와 같이 쓸 수 있다.
			- ```js
			  const result = array.filter(item => item > 10);
			  ```
			- 배열의 변환과 마찬가지로 메서드를 연계할 경우 코드 가독성을 개선할 수 있다.
			- ```js
			  // 조건 2개 + 변환
			  const temp1 = [];
			  for (let item of array) {
			      if (item > 10) temp1.push(item);
			  }
			  const temp2 = [];
			  for (let item of temp1) {
			      if (item < 100) temp2.push(item);
			  }
			  const result = [];
			  for (let item of temp2) {
			      result.push(item * 2);
			  }
			  ```
			- 위 코드를 아래처럼 간단하게 기술할 수 있다.
			- ```js
			  const result = array
			      .filter(x => x > 10)
			      .filter(x => x < 100)
			      .map(x => x * 2);
			  ```
		- #### 압축
			- 배열 하나를 다양한 방법으로 처리해야 할 경우 체이닝을 사용할 수 있다. 체이닝이 없다면 결과값을 계속 넘겨 주며서 코드를 작성해야 하고 결과적으로 가독성이 떨어진다.
			- ```js
			  // for: 중첩 지옥
			  const filtered = [];
			  for (let item of array) {
			      if (item > 10) filtered.push(item);
			  }
			  const doubled = [];
			  for (let item of filtered) {
			      doubled.push(item * 2);
			  }
			  const sum = 0;
			  for (let item of doubled) {
			      sum += item;
			  }
			  ```
			- 함수형으로 선언하면 여러 메서드를 사슬처럼 연결(method chaining)해 너저분한 코드가 필요없다.
			- ```js
			  const sum = array
			      .filter(x => x > 10)
			      .map(x => x * 2)
			      .reduce((a, b) => a + b, 0);
			  ```
			- 단, 위와 같이 작성하면 세 번의 순회(interation)이 생기고 각 단계마다 익명 배열을 생성한 뒤 결과값을 `sum`에 저장한 뒤 해당 익명 배열을 삭제 대상으로 분류한다.
			- 이를 고려해 아래와 같이 단일 순회로 처리하는 방법도 있다. 순회가 수만 건 이상이라면 유의미한 차이가 있을 수도 있다. 한 번의 순회로 원하는 결과를 얻을 수 있다.
			- ``` js
			  // 메모리와 성능을 모두 잡는 고수의 방식 (단 한 번의 루프)
			  const sum = array.reduce((acc, x) => {
			      if (x > 10) acc += x * 2;
			      return acc;
			  }, 0);
			  
			  // 혹은 콜백을 별도로 선언해 아래와 같이 작성해도 좋다.
			  const calculateTotal = (currentSum, nextValue) => {
			      return nextValue > 10 ? currentSum + nextValue * 2 : currentSum;
			  };
			  const total = array.reduce(calculateTotal, 0);
			  ```
