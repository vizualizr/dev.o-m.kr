- ## Steps
	- ### 탐색적 데이터 분석
		- 방대한 데이터를 가시화하기 전에 데이터의 정제, 포맷팅, 준비하는 과정이 필요하다.
		- 이는 위 단계에서 1번과 2번 사이에 위치하며 데이터 정제와 가공을 수행하는 단계이다.
		- 이 단계를 탐색적 분석(exploratory analysis) 혹은 탐색적 데이터 분석(exploratory data analysis)이라 한다. 이 과정에서 다음을 반드시 수행해야 한다.
			- 데이터의 명시적 구조를 파악한다. 행 / 열의 구성과 각 데이터의 자료형을 확인한다.
			- 이상치, 결측치를 반드시 점검한다. 가능하면 해당 결측치의 원인 또한 밝히는 것이 좋다. 필요한 경우 이를 데이터 생산자/소유자에게 고지해야 한다.
			- 시각화 가능성을 검증한다. 이 지점이 가장 중요하다.
				- 정량화 가능하므로 시각화 가능하겠지만 시각적으로 유의미한가 굳이 시각화의 도움일 필요한가는 별개의 문제다.
			- d3.js에 적합한 형식으로 자료를 구조화할 수 있는지 파악해야 한다.
			- 위 선결 과제가 끝나면 데이터를 시각화에 최적화된 구조로 가공한다.

		- 작업할 원본 데이터를 Kaggle 서버에 안전하게 올리는 기능입니다.
		- **사용 방법:**
			- Kaggle 메인 화면 좌측 메뉴에서 **'Datasets'**를 클릭합니다.

			- 로컬에 있는 CSV, Excel, JSON 파일을 드래그 앤 드롭하여 업로드합니다.
		- ## 2. Kaggle Notebooks (코드 작성 및 실행 환경)
		  
		  Pandas 코드를 작성하여 데이터를 탐색하고 정제하는 핵심 작업 공간입니다. (Jupyter Notebook과 동일한 환경 제공)
		- **사용 방법:**

		- ## ① 명시적 구조 파악
		- **Kaggle 기능:** Notebook 내부의 **Data Explorer UI** 및 **Pandas 기본 함수**
		- **어떻게 사용하나:** Notebook 우측 패널의 'Input' 섹션에서 데이터 파일명을 클릭하면 코드를 치지 않고도 행/열 구조와 샘플 데이터를 가시적으로 보여줍니다.
		- **코드 실행:** 셀에 아래 코드를 입력하여 데이터 타입을 검증합니다.
		  
		  ```
		  import pandas as pd
		  df = pd.read_csv('/kaggle/input/본인데이터이름/file.csv')
		  df.info() *# 행/열 개수, 메모리, 자료형(Dtype) 일괄 확인*
		  ```
		- ## ② 이상치, 결측치 점검
		- **Kaggle 기능:** **Interactive Table View** 및 **Pandas 결측치 시각화**
		- **어떻게 사용하나:** 결측치를 시각적으로 빠르게 훑기 위해 내장된 인터랙티브 테이블 뷰 필터를 활용하거나 코드로 진단합니다.
		- **코드 실행:**
		  
		  ```

		  *# 이상치 파악을 위한 기술통계량 확인 (최대값, 최소값, 사분위수)*
		  df.describe()
		  ```

		- **Kaggle 기능:** 내장 **Matplotlib / Seaborn** 라이브러리 활용
