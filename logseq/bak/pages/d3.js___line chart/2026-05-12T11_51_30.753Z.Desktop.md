- ## Summary
	- 선을 그리는 함수 객체를 생성한다. 기본 모양은 각 점을 잇는 직선이며 필요하다면 이를 곡선으로 대체할 수 있다.
	- 선이 들어갈 DOM 요소를 선언한다.
	- 선언한 DOM 요소에 `path` 요소를 추가한 뒤 앞에서 선언한 함수 객체로 선 모양을 생성해 `path`요소의 속성 `d`의 값으로 지정한다.
- ## Steps
	- ###  1. SVG 요소 내부에서 여백을 지정 / Setting margins
		- 📖 See “The margin convention” ([Meeks, 2024, p. 117](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=143&annotation=R3Y3AR63)) for the details.
		- ![image.png](../assets/image_1777275451014_0.png)
		- Following the convention above. Found at the “Figure 4.4 Knowing the dimensions of the SVG container and the margins, we can calculate the inner chart’s width and height.” ([Meeks, 2024, p. 119](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=145&annotation=CA9GDREX))
		- ```js
		    const width = 1000;
		    const height = 500;
		    const margin = {
		      top: 35,
		      bottom: 25,
		      left: 40,
		      right: 170,
		      get horizontal() {
		        return this.left + this.right;
		      },
		      get vertical() {
		        return this.top + this.bottom;
		      },
		    };
		  // innerWidth is the 
		    const innerWidth = width - margin.horizontal;
		    const innerHeight = height - margin.vertical;
		  ```
		- `innerWidth`, `innerHeight`은 척도(Scale)를 사용해 주어진 자료의 값이 좌표 평면에서 어느 지점에 계산할 수 있는 기준 거리이다. EN {{cloze The `innerWidth` and `innerHeight` are the reference distances for a d3.js *Scale* object to evaluate the coordinates of a given datum on the coordinate plane.}}

	- ### 3. 선 만들기
		- > “Drawing a line chart” ([Meeks, 2024, p. 128](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=154&annotation=LV3GIE63))
		- d3.js deploys `path` element in SVG to draw lines. SVG의 선 요소인 `path`를 그대로 활용한다.
		- 그려야 할 선 모양을 지시하는 명령어 구문을 생성해 `path`의 `d` 속성에 넣으면 선을 그릴 수 있다. 아래 문자열과 같다.
			- ```text
			  /* M 10,30
			         A 20,20 0,0,1 50,30
			         A 20,20 0,0,1 90,30
			         Q 90,60 50,90
			         Q 10,60 10,30 z */
			  <!-- SVG의 path 요소는 위 명령어가 지시하는 내용에 따라 선을 그린다. -->
			  ```
		- 선의 모양이 복잡할 수록 `d`의 값도 복잡해진다. d3는 선 모양을 지정하는 명령어를 생성하는 함수 객체, `d3.line()`을 생성할 수 있다. 생성하는 구문은 아래와 같다.
			- ```Js
			    // 선을 그리는 함수 객체를 먼저 생성한다.
			    // d3.line()은 접근자 함수를 이용해 함수 객체를 생성해 반환한다.
			  const lineGenerator = d3
			      .line()
			      .x((datum) => xScale(datum.date))
			      .y((datum) => yScale(datum.avg_temp_F));
			  ```
		- `path` 요소를 원하는 곳에 생성한 후 `attr()`로 속성 `d`의 값을 지정하면 이에 해당하는 선을 그린다. 아래와 같다.
			- ```js
			  .attr("d", lineGenerator(data)) // d 속성에 lineGenerator로 선을 그리는 명령줄을 추가한다.
			  ```
			- `d3.line()`로 생성한 함수 객체는 아래에서 속성 `d`에 해당하는 문자열을 반환한다.
				- ```html
				  
				  <svg id="svg_css_ex1" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
				    <path
				      fill="none"
				      stroke="red" 
				          <!-- d is a sequence of commands and numbers to draw the lines alongside the given points -->
				      d="M 10,30
				         A 20,20 0,0,1 50,30
				         A 20,20 0,0,1 90,30
				         Q 90,60 50,90
				         Q 10,60 10,30 z
				         " />
				  </svg>
				  ```
	- ### 선 그래프를 보간하는 방법
		- 해당 내용을 다음을 요약한다. “4.2.2 Interpolating data points into a curve” ([Meeks, 2024, p. 132](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=158&annotation=QUPIC5JQ))
		- 선을 그리는 함수 객체에 체이닝을 추가하면 선 모양을 곡선으로 만든다.
		- ```js
		  const curveGenerator = d3.line()
		  .x(d => xScale(d.date))
		  .y(d => yScale(d.avg_temp_F)
		  // 아래 줄을 추가해 
		  .curve(d3.curveCatmullRom);
		  ```
		- 직선 그래프 대신 조금 더 자연스러운 모양을 구현한다. 단 실제값과 달라지는 경우가 있으니 반드시 결과를 확인해야 한다. “The interpolation of lines is particularly vulnerable to misuse because it changes a clunky-looking line into a smooth, “natural” line.” ([Meeks, 2024, p. 133](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=159&annotation=7WDYA45U))
		- 구체적인 예시는 아래와 같다.
		- “Figure 4.17 Different curve interpolations and how they modify the representation of data” ([Meeks, 2024, p. 134](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=160&annotation=4SGQK9QP))

- ## Troubleshooting
	- What is `d` attribute in SVG?
	  collapsed:: true
		- “In chapter 1, we discussed how the d attribute is made of a series of commands that dictate how to draw a shape.” ([Meeks, 2024, p. 128](zotero://select/library/items/VHTGXJRT)) ([pdf](zotero://open-pdf/library/items/FGBNWKIT?page=154&annotation=SJ2A5EPU))
		- ```html
		  <svg id="svg_css_ex1" viewBox="0 0 100 100" xmlns="http://www.w3.org/2000/svg">
		    <path
		      fill="none"
		      stroke="red" 
		          <!-- d is a sequence of commands and numbers to draw the lines alongside the given points -->
		      d="M 10,30
		         A 20,20 0,0,1 50,30
		         A 20,20 0,0,1 90,30
		         Q 90,60 50,90
		         Q 10,60 10,30 z
		         " />
		  </svg>
		  ```
		- https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/d
		- This is complex so d3.js provides other alternative way to draw lines in different kind with concise code.
